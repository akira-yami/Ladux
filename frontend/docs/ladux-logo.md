# LADUX Sky logo

Asset: `../src/assets/ladux-logo-sky.png` (2073 × 758, PNG with alpha).

Generated with the built-in imagegen tool. Original alpha preserved. The source
asset is kept separately from the admin logo. `BrandMark.tsx` renders the logo
with its natural aspect ratio, a smaller mobile width and accessible LADUX text.
The storefront header, authentication header and footer use this shared component.
