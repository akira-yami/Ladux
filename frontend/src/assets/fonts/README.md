# UI font

`InterVariable.woff2` is the official Inter variable font, used locally for all UI text including Vietnamese. It supports weights 100–900; `styles/fonts.css` declares the face and `styles/design-system.css` shares it with Tailwind's `font-sans` utilities.

Source: https://rsms.me/inter/font-files/InterVariable.woff2

License: SIL Open Font License, included verbatim in `Inter-LICENSE.txt` from https://github.com/rsms/inter/blob/master/LICENSE.txt.

The app does not need Google Fonts to render the interface. Monospace content uses the available local monospace fallback.
